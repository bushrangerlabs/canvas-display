## Default Permission

Default permissions for the multiwebview plugin — allows all panel management and screen control commands.

#### This default permission set includes the following:

- `allow-create-panel-webview`
- `allow-navigate-webview`
- `allow-close-webview`
- `allow-show-webview`
- `allow-hide-webview`
- `allow-get-all-webview-labels`
- `allow-screen-off`
- `allow-screen-on`
- `allow-set-brightness`
- `allow-keep-screen-on`
